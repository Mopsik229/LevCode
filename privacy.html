Соглашение об обработке персональных данных

Настоящее Соглашение об обработке персональных данных (далее — «Соглашение») действует в отношении всех персональных данных, которые пользователь сайта https://levcode.ru (далее — «Сайт») может предоставить в процессе его использования.

1. Общие положения

1.1. Используя Сайт, заполняя любые формы обратной связи, формы расчёта стоимости проекта или иные формы на Сайте, пользователь подтверждает своё согласие на обработку персональных данных на условиях, изложенных в настоящем Соглашении.

1.2. Оператором персональных данных является Оператор.

1.3. Согласие на обработку персональных данных даётся пользователем свободно, своей волей и в своём интересе.

2. Персональные данные, подлежащие обработке

2.1. Оператор обрабатывает персональные данные, которые пользователь указывает самостоятельно при заполнении форм на Сайте, в том числе:

  • имя;
  • номер телефона;
  • адрес электронной почты;
  • содержание сообщения (описание проекта, задачи, пожелания);
  • иные данные, добровольно указанные пользователем в текстовых полях форм Сайта.

2.2. Оператор не собирает специальные категории персональных данных (сведения о состоянии здоровья, религиозных убеждениях и т.п.) и просит пользователя не указывать такие данные в формах Сайта.

3. Цели обработки персональных данных

3.1. Персональные данные обрабатываются в целях:

  • обратной связи с пользователем по оставленной заявке;
  • расчёта стоимости и условий разработки проекта;
  • уточнения деталей задачи и подготовки коммерческого предложения;
  • направления пользователю ответов, документов и материалов по его запросу.

3.2. Персональные данные не используются для целей, не связанных с указанными выше, без отдельного согласия пользователя.

4. Условия обработки персональных данных

4.1. Обработка персональных данных осуществляется в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

4.2. Обработка может осуществляться как с использованием средств автоматизации, так и без них.

4.3. Оператор не передаёт персональные данные третьим лицам, за исключением случаев, прямо предусмотренных законодательством РФ, либо когда это необходимо для оказания услуг, заказанных пользователем (например, использование почтовых сервисов, мессенджеров или сервисов аналитики для связи с пользователем).

4.4. Доступ к персональным данным имеет только Оператор.

5. Хранение и защита персональных данных

5.1. Персональные данные хранятся не дольше срока, необходимого для достижения целей их обработки, если иной срок не установлен законом.

5.2. Оператор принимает разумные организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, раскрытия или уничтожения.

6. Права пользователя

6.1. Пользователь вправе:

  • получить информацию, касающуюся обработки его персональных данных;
  • потребовать уточнения, блокирования или уничтожения персональных данных в случае, если они неполны, устарели, неточны или получены с нарушением закона;
  • отозвать согласие на обработку персональных данных, направив соответствующее уведомление Оператору на адрес электронной почты info@levcode.ru или через контактную форму Сайта.

7. Заключительные положения

7.1. Оператор вправе вносить изменения в настоящее Соглашение. Действующая редакция Соглашения всегда размещена на Сайте.

7.2. Продолжая использовать Сайт после внесения изменений, пользователь подтверждает согласие с актуальной редакцией Соглашения.

7.3. По всем вопросам, связанным с обработкой персональных данных, пользователь может обращаться к Оператору по контактным данным, указанным на Сайте.
